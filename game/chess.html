中國象棋玩法與規則說明

一、基本規則與勝負判定

  • 紅先黑後：開局由紅方先走，雙方輪流每次移動一子。
  • 將死與困斃：將對方的「帥／將」將死（無法解救），或使對方無任何合法步數可走（困斃），即獲勝。
  • 王不見王：紅「帥」與黑「將」不可在同一直線上直接照面（中間無任何棋子阻隔），走棋後若造成照面則該步無效。

二、七大兵種走法口訣

帥 / 將（統帥）

只能在己方「九宮格」內上下左右移動一格，不可出九宮，且不可與對方將帥照面。

仕 / 士（護衛）

只能在己方「九宮格」內沿斜線走一格，負責貼身保護主帥。

相 / 象（飛田塞眼）

沿對角線走「田」字（兩格），不可過「楚河漢界」。若田字中心有棋子阻擋（塞象眼），則不能飛過。

俥 / 車（橫衝直撞）

橫向或縱向任意行走，格數不限，只要路徑無阻擋即可吃子，威力最強。

傌 / 馬（日字蹩腿）

走「日」字（先直或橫走一格，再斜走一格）。若緊鄰的直/橫向第一格有棋子（蹩馬腿），則該方向不可跳躍。

炮 / 包（隔山打牛）

不吃子時走法與「車」相同；吃子時必須與目標之間隔著正好一個任意棋子（炮架）。

兵 / 卒（有進無退）

過河前每次只能向前走一格；過「楚河漢界」後，除了向前外，還可向左或向右橫走一格，永遠不能後退。

三、操作提示

  • 點擊己方棋子後，棋盤上會以綠點標示可移動空位，紅框標示可吃掉的敵方棋子。
  • 支援隨時切換「人機對戰」或「雙人對奕」，並可使用右上角「全螢幕」獲得最佳沉浸體驗。
